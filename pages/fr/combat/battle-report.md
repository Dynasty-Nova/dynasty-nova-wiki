# Lire un rapport de combat

> **En bref** : un rapport de combat donne, pour chaque camp, les unités engagées, perdues et survivantes, puis le résultat, le butin et le champ de ruines créé. Chaque combat peut être rejoué à l'identique.
{.is-info}

## Règles

1. Pour **chaque camp**, le rapport liste les unités **engagées**, **perdues** et **survivantes**.
2. Le **résultat** est l'un des trois : victoire de l'attaquant, victoire du défenseur, égalité.
3. En cas de victoire de l'attaquant, le rapport indique le **butin** emporté (métal, cristal, hydrogène).
4. Il indique aussi le **champ de ruines** créé (métal et cristal).
5. **Vue partielle** : vous ne voyez que les unités ennemies réellement engagées dans le combat.
6. Si votre **Station de réparation** a récupéré des vaisseaux, ils apparaissent dans les pertes, avec une mention : ils reviendront une fois réparés.
7. Si une **lune** se forme à partir des débris, le rapport le signale.
8. Chaque combat est **déterministe** : il peut être rejoué et donnera exactement le même résultat.
9. Le rapport peut être **partagé** avec votre alliance.

## Exemple chiffré

Vous attaquez avec 20 Assaillants et 5 Cargos stellaires une planète défendue par 10 Projecteurs balistiques. Le rapport indique :
- Attaquant : 25 engagés, 3 Assaillants perdus, 22 survivants.
- Défenseur : 10 Projecteurs engagés, 10 perdus. Victoire de l'attaquant.
- Champ de ruines : 30 % de 3 × (6 000 métal + 4 000 cristal), soit **5 400 métal et 3 600 cristal**. Les Projecteurs détruits ne laissent aucun débris.
- Côté défenseur, chaque Projecteur détruit a ensuite 70 % de chances d'être réparé.

## Pièges fréquents

- **Les pertes affichées peuvent revenir** : les vaisseaux récupérés par la Station de réparation sont comptés dans les pertes.
- **Les défenses perdues aussi** : 70 % reviennent en moyenne après le combat.
- **Une égalité ne rapporte rien** : pas de butin.
