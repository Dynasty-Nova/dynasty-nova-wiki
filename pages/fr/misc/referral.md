# Parrainage

> **En bref** : invitez des joueurs avec votre lien de parrainage. Quand un filleul atteint 100 points dans un univers, vous recevez 30 Points stellaires.
{.is-info}

## Règles

1. Chaque joueur dispose d'un **lien de parrainage** sur la page Parrainage.
2. Quand un filleul atteint **100 points** dans un univers, vous recevez **30 Points stellaires**.
3. Le **multi-compte est interdit** : vous parrainer vous-même avec un second compte n'est pas permis.

## Exemple chiffré

Trois amis rejoignent le jeu avec votre lien et atteignent chacun 100 points : vous recevez 3 × 30 = **90 Points stellaires**.

## Pièges fréquents

- **La récompense n'est pas immédiate** : elle arrive quand le filleul atteint 100 points, pas à son inscription.
